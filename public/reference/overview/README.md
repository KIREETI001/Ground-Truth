# Programming Languages Reference Library

A comprehensive multi-file reference covering seven languages widely used in 2026: Python, JavaScript, TypeScript, Java, C#, C++, and SQL.

## Structure

Each language has its own folder with thematic files. Read the folder's `README.md` first for navigation and reading order.

| Folder | Files | Lines | Best for |
|---|---|---|---|
| `python/` | 16 | ~11,900 | Data, ML/AI, web backends, scripting, general-purpose |
| `javascript/` | 16 | ~10,000 | Web frontend, Node.js backends, full-stack |
| `typescript/` | 10 | ~5,700 | Type-safe JavaScript; React, Node, large codebases |
| `java/` | 16 | ~12,300 | Enterprise backends, Android, JVM ecosystem |
| `csharp/` | 16 | ~11,600 | .NET, Windows, Unity game dev, enterprise |

| `sql/` | 9 | ~6,800 | Databases, analytics, data engineering |

**Total: 99 files, ~70,000 lines.**

## How each language folder is organized

Each folder follows a parallel structure:
- `README.md` — overview, mental model, reading order
- `01_setup.md` (or `01_basics.md` for SQL) — installation, hello world, fundamentals
- Subsequent files — language features, standard library, frameworks, advanced topics
- Final file — common pitfalls and idioms

## Style

- Markdown throughout.
- Beginner-friendly: concepts explained before code.
- Direct advisory tone — no warm-up paragraphs.
- Each file has a table of contents at the top and key principles at the end.

## Suggested reading paths

**Coming from another language?** Start with that language's README, then `01_setup` and `02_language_basics`. Skip ahead to topics relevant to your work.

**New to programming?** Start with Python — most accessible. Then JavaScript for web, or SQL for data work.

**Building a backend?** Pick one of Python, Node (JavaScript/TypeScript), Java, C#. Pair with SQL.

**Building games?** C++ (engines) or C# (Unity). Maybe JavaScript for web games.

**Doing data/ML?** Python + SQL.

## Coverage

Modern features: Python 3.13+, Node 22 LTS, Java 21/25 LTS, .NET 10 LTS, C++20/23, modern SQL (PostgreSQL primary, with MySQL/SQLite/SQL Server/BigQuery/Snowflake notes).

Each language's framework coverage focuses on the dominant choices in 2026 — FastAPI/Django for Python, React/Next.js for JS/TS, Spring Boot for Java, ASP.NET Core for C#, etc.
