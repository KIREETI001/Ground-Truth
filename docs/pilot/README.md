# GroundTruth pilot kit

This is a reusable kit for two internal rehearsals followed by five adult volunteer sessions. It is a plan, not a record of completed testing. Check [operator gates](operator-checklist.md) before arranging a real session. Human moderators handle recruitment and consent; this kit does not authorize sending invitations.

| Material | Use |
| --- | --- |
| [Recruitment and consent](recruitment-and-consent.md) | Human-sent invitation, coarse screening, and separate consent choices. |
| [Moderator script](moderator-script.md) | Neutral 35–45 minute session; preserve independent transfer. |
| [Observation sheet](observation-sheet.md) | Copy privately per participant; record behavior, assistance, build, and evidence IDs. |
| [Manual rubric](manual-rubric.md) | Three diagnostic dimensions, 0–3, separately for main work and transfer. |
| [Operator checklist](operator-checklist.md) | Configuration, release, stop conditions, purge, and recovery. |

Recruit target-fit people learning web apps or using AI-generated code. Internal team rehearsals are excluded from participant results. Use synthetic data throughout. Record the build each person encountered, including changes after the first two participants.

Core practice and tutor review may use retained original work under the disclosed notice. Optional research is a separate choice: include only consented structured counts, timing, choices, and manual rubric values. **Raw answers, quotations, transcripts, and notes are excluded from research analysis and research exports, even with research consent.** Recording defaults off; public quotes, images, or demo clips require separate specific permission. Declining research preserves core practice access.

Own deletion synchronously removes learning activity and its derivatives. A separate native-account-linked enrollment attempt counter can remain active for its ten-minute window to prevent deletion resetting the security limit. Expired counters require operator cleanup or a later own deletion request; physical cleanup is not automatic. Read this exception in the consent notice and record the deletion response's retained-counter information when applicable.

Keep completed sheets, contact lists, exports, and answer keys private. Use pseudonyms in engineering issues and aggregate reports. Do not commit participant content or operational logs. Read original work for core tutor review only within authorized access; record the structured scoring profile separately.

Report attended, consented, completed, assisted, and independent counts with exact denominators. Preserve stops, missing data, unavailable AI, and contaminated transfer. Five convenience-sample sessions can identify usability problems and examples of reasoning; they cannot establish learning gains, retention, fair grading, or tutor time savings. If no real users have run, say so.
