# External practice resources

GroundTruth's original mini missions teach concept selection and reading code. The following are ordinary external practice destinations; there is no account integration, affiliation, completion synchronization, certification guarantee, or copied provider problem content.

Verified against official pages during the learning-experience redesign on 28 October 2026. Providers can change their resources and requirements; follow the destination's current instructions.

| Destination | How it fits |
| --- | --- |
| [LeetCode: 30 Days of JavaScript](https://leetcode.com/studyplan/30-days-of-javascript/) | A beginner JavaScript study plan for broader practice. |
| [LeetCode: Programming Skills](https://leetcode.com/studyplan/programming-skills/) | A broader implementation-practice plan; it is not exclusively a two-pointer collection. |
| [Codewars: JavaScript kata](https://www.codewars.com/kata/search/javascript) | Choose a relevant Fundamentals task; its [official guide](https://docs.codewars.com/getting-started/finding-kata/) suggests Fundamentals and the easiest 8/7 kyu levels for newcomers. |
| [Exercism: JavaScript concepts](https://exercism.org/tracks/javascript/concepts) | Language-specific concept explanations and practice. Related pages cover [loops](https://exercism.org/tracks/javascript/concepts/for-loops) and [objects as key-value collections](https://exercism.org/tracks/javascript/concepts/objects). Objects are not identical to JavaScript's `Map` class. |
| [HackerRank: Problem Solving (Basic)](https://www.hackerrank.com/skills-verification/problem_solving_basic) | Optional external assessment; completing GroundTruth does not predict a pass or earn its certificate. |

The main signup investigation's independent task remains separate from this path. The mini missions do not teach that task's specific retry/key-scope solution or unlock its server phases.
