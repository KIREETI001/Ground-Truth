# GroundTruth — three-minute local MVP pitch

“AI can help us build a working project before we understand it. GroundTruth helps the builder explain the code, make a deliberate change and show what they can reason through independently.”

1. **0:00–0:25 — Entry.** Show the animated journey and common login. Users sign up, teachers request approval, developers are preconfigured. The profile chooses the workspace.
2. **0:25–0:55 — Project map.** Open an ordinary User account or the labelled developer learner preview. Paste a public repo and show its generated feature overview. Choose Backend and a specific workflow; relevant source is selected automatically. Pick improvement mode or learning from a reference, and set a goal. Show the pinned commit and a source-linked review question. This is selected-source guidance.
3. **0:55–1:20 — Concepts.** Show the generated concept tree. Its structure stays familiar across repositories while its nodes come from the actual source. Choose a focus.
4. **1:20–2:00 — Changes.** For improvement mode, use your own repository's separate copy to show a manual change or ask local AI for one small proposal. For reference mode, show Apply skills and generate an adaptation challenge for your own target project instead. On the improvement path, read the summary and diff, approve and apply. The original checkout and GitHub stay unchanged. A prepared small example keeps the demo moving without pretending generation is instant.
5. **2:00–2:35 — Practice.** Generate a short question against the chosen workflow or edited file, or use the target-specific adaptation challenge. Start independent mode: assistance pauses. Commit a clearly labelled demo answer, retained before reflection.
6. **2:35–3:00 — Progress.** Show the linked concept's unreviewed evidence and activity counts. Explain the provisional index. With separate approved accounts prepared, show explicit sharing and human teacher review. Never present a synthetic answer as a real student's learning result.

“GroundTruth makes the path from generated code to personal understanding inspectable: source, concept, reviewed change, independent explanation and human review. The demo runs on this laptop with local inference.”

Public GitHub import needs internet. Do not claim external-AI detection, verified mastery, full-repository certification or measured learning gains. Generated explanations can be wrong; checking them against source is part of the workflow.
