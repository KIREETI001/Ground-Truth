# Repository learning entry

The learner's primary action is choosing a workflow to strengthen, not identifying a source filename. Keep the existing calm paper/green visual language. Hierarchy: purpose → repository overview → learning area → concrete workflow → focused learning. Source paths are inspectable details, never required input. Use native radio groups, pressed area filters and labelled buttons/forms. Cards wrap on narrow screens; the five stage navigation remains consistent.

| State | Trigger, feedback and next action |
| --- | --- |
| Empty | No source yet; explain both purposes, ask for a public URL and consent |
| Loading | GitHub scan/local generation; show the current operation and disable duplicate submission |
| Error | Missing source, rate limit or invalid model output; preserve input and offer the same explicit retry |
| Partial | Bounded/truncated catalogue or sampled source; disclose coverage and let the learner inspect it |
| Ready | Show generated features and concepts, area filters, workflow selection and optional personal goal |
| Transfer | Require a target goal; make the reference read-only and offer a generated adaptation challenge |
| Improvement | Retain original diff review, permission assertion and explicit apply safeguards |
| Independent | Backend blocks new generation and edits until the learner commits an answer |

Maps are stored privately for 24 hours and can be reused to explore another area. A focused path persists its purpose, area, feature and target separately from source snapshots and concept evidence. Teachers see this context with explicitly shared work. Previously saved file-based projects continue to open; the new entry no longer presents their legacy file picker.

Validation covers map ownership/pilot/expiry, bounded balanced sampling, rejection of invented citations and IDs, automatic pinned import, reference-mode edit denial, transfer-context generation and independent-mode locking. Real local model/browser testing is required because schema-valid output alone does not establish a useful learning map.
